谷歌分析配置指南

目标很简单：所有网站共用一套谷歌分析账号；访客打开聊天、提交询盘时自动记一笔； 后台「询盘分析」里能看到流量。按下面顺序做即可，不必了解技术术语。

请先记住两件事：
1）谷歌分析在本系统里是全账号统一配置（不是每个站点各配一套）。
2）看数据时，系统会按网站域名自动区分不同站点。

1 在谷歌分析拿到「衡量 ID」

  1. 用浏览器打开 analytics.google.com 并登录。
  2. 左下角点齿轮图标「管理」。
  3. 中间一列找到「数据流」→ 点开你的网站数据流（没有就新建一个「网站」数据流，填入主站网址）。
  4. 页面上方会看到以 G- 开头的一串字符，例如 G-ABC123XYZ。把它复制下来。
    这一串叫「衡量 ID」。后面只要填这一项，聊天事件就能进谷歌。

2 在本系统里粘贴并保存

  1. 登录客服后台 → 左侧或顶部进入 设置 → 打开 谷歌分析 页签。
  2. 勾选「启用聊天事件上报」。
  3. 在「衡量 ID」输入框粘贴刚才的 G-…。
  4. 点页面右上角 保存设置。
  5. 等大约 5 分钟（或硬刷新业务网站），再测试。

说明：这一项对所有站点生效。各站点网页只要已嵌入本系统的聊天挂件，就会用同一套衡量 ID 上报。

3 确认网站已嵌入挂件（只插一段）

  1. 在后台「设置 → 代码嵌入」复制挂件代码。
  2. 粘贴到每个业务网站 HTML 的 </body> 前。
  3. 每个页面只放这一段脚本，不要重复粘贴多遍。
  4. 该网站的域名必须已在本系统「站点」里登记为授权域名。

4 验证事件是否进了谷歌（约 1 分钟）

  1. 打开谷歌分析 → 左侧「报告」→「实时」。
  2. 用手机或另一个浏览器打开你的业务网站，点开聊天挂件，发送一条消息，或提交一次表单/留言。
  3. 在实时报告里应陆续看到类似事件：
    事件名含义
    chat_open打开了聊天窗口
    chat_engaged产生了有效互动
    inquiry_submit提交了询盘 / 表单 / 留言

若实时里没有：检查衡量 ID 是否以 G- 开头、是否已保存、域名是否授权、是否只嵌入了一段挂件。

5（可选）让后台「询盘分析」也能拉谷歌报表

做到第 4 步，你已经可以在谷歌分析网站里看数据。若还希望在本系统询盘分析页直接看到访问量，继续下面任一方式。

方式 A：连接谷歌账号（适合自己操作）

  1. 打开 Google Cloud 控制台，选一个项目（没有就新建）。
  2. 搜索并启用这两个接口：
    • Google Analytics Data API
    • Google Analytics Admin API
  3. 进入「Google Auth Platform / 凭据」→ 创建「OAuth 客户端 ID」→ 类型选「Web 应用」。
  4. 「已获授权的重定向 URI」填（把域名换成你的后台域名）：
    https://你的后台域名/api/analytics/ga/oauth/callback
  5. 把生成的「客户端 ID」「客户端密钥」填回本系统「谷歌分析」页 → 先点保存设置 → 再点「连接谷歌账户」并授权。
  6. 点「刷新媒体资源列表」，选中你的 GA4 媒体资源，勾选「允许询盘分析拉取谷歌报表」，再保存。

方式 B：由技术人员配置服务账号（一次配好，后台几乎不用再点）

若系统由服务商托管，可请对方在 Cloudflare Worker 机密中配置服务账号，并在谷歌分析里给该邮箱「查看者」权限。配置成功后，设置页会显示「报表通道已开通」。

6 日常怎么看数据

你想看什么去哪里
聊天有没有记上、刚发生的事件 谷歌分析 → 报告 → 实时
按网站域名拆开看流量 谷歌分析探索 / 报告里用「主机名」；或本系统「询盘分析」（会按当前站点域名筛选）
本系统自己的询盘漏斗（不依赖谷歌） 后台 → 询盘分析
常见问题

为什么不是每个站点单独填一套 G-？
一套衡量 ID 更简单，也方便对比各站。系统上报时会带上当前网站域名，查询时按域名区分。

网站自己已经装了谷歌统计怎么办？
可以。挂件会尽量复用页面上已有的谷歌标签，一般不会再插第二份脚本。仍请在本系统填写同一个衡量 ID，以便发送聊天相关事件。

保存后没变化？
挂件配置有短暂缓存，请等待数分钟或强制刷新页面后再试。
